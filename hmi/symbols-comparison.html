How each is built

SymbolComposition
SiloCylinder body with a darker strip down one side so it reads round, a level fill, then a conical outlet from two opposed diagonal lines, legs and outlet nozzle.
PumpCircle casing, smaller circle impeller, rectangular suction and discharge nozzles declared before the casing so it frames them, baseplate and feet.
PipeA run and a drop meeting at an elbow, flanges at both ends, and a reducer made the same way as the cone, rotated.
MotorBody with a shaded lower band, four cooling fins, terminal box, output shaft, mounting feet, and a circled M declared last of all.

All grey by design. These are process-area graphics and colour is reserved for the abnormal, so a symbol carries shape and label but never a hue.

A circle crashed TIA Portal, and the coherence gate did not catch it. The motor's mark was authored 36 × 34 with a radius of 17 — but a radius-17 circle is 34 × 34, so the width was two pixels of nonsense. TIA does not reject an object whose parts contradict each other; the process dies with "Access to a disposed object".

The gate already had a rule for exactly this class — written after a Line crashed the same way — and it did not generalise. "The parts contradict each other" takes a different form in every shape, so the gate needs one rule per shape, and the next new shape should be assumed to bring a third.

Two checker rules also turned out to be wrong about legitimate work. H-203 flagged border-radius: 50% on the circles — which is simply how a circle is written in CSS; a rule that fires on the correct way to do something trains people to ignore it. And H-504 flagged the pump's impeller against the motor's label, two objects 400 px apart whose only relationship is sitting near the same y. That one is overridden with its reason rather than "fixed": snapping unrelated things into alignment would be gaming the check.

The primitive that was missing

A bounding box has two diagonals and CSS cannot say which one a div is, so only top-left-to-bottom-right was reachable. Cones, roofs and reducers were undrawable. Adding data-hmi-line="up" made the opposed pair expressible, and the silo's cone and the pipe's reducer both depend on it.

Still absent: Polygon, which the Unified reference corpus uses 84 times. Everything here was reachable without it, but an arbitrary closed shape is not.
